## Overview

The official corporate web platform for **KRAD Technology**, engineering digital experiences and scalable products for startups, SMBs, and global enterprises.

### Key Capabilities
- **70% Minimalist + 30% Interactive 3D:** Dark navy/charcoal styling with responsive Three.js WebGL particle sphere and mobile-optimized SVG/CSS fallback.
- **11 Service Verticals:** Web Apps, Mobile Apps, AI Business Solutions, Custom Software, Graphic Design, Video Editing, VFX/Animation, Logo/Branding, UI/UX, Mobile Design, and Agile Project Management.
- **Dynamic 6-Language Engine:** English, Spanish, German, French, Hindi, and Arabic (with full RTL support).
- **Authenticated Admin CMS (`/admin`):** Real-time lead tracking (Inquiries, Resource Hires, 5-Step Project Requirements) and live website copy/translation editing.
- **Enterprise Security:** Built-in CSP headers, distributed rate limiting, anti-spam honeypots, and Zod validation.

## Tech Stack
- **Framework:** Next.js 15+ (App Router)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS
- **Database:** Supabase (Hosted PostgreSQL)
- **3D & Visuals:** Three.js (Lazy-loaded WebGL)
- **Icons:** Lucide React

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env` and provide your Supabase keys.

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)

### 4. Build for Production
```bash
npm run build
npm run start
```
